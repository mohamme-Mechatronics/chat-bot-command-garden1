# تطبيق الإدارة المحلي

الصفحات مضمّنة داخل التطبيق وليست نافذة تفتح موقعًا ثابتًا. يبقى الإنترنت وخدمة البيانات وn8n مطلوبين لقراءة العملاء واستقبال الرسائل والرد. لا توجد نسخة غير متصلة من محادثات العملاء.

## إعادة التجهيز
من مجلد المصدر، ثبّت Node.js 22+ وBun ثم:

```sh
bun install --frozen-lockfile
bun run native:build
```

أضف ملف `.env` محليًا من نموذج `.env.example` ومعلومات الاتصال العامة الخاصة بمشروعك؛ لا تضف مفاتيح إدارية إلى التطبيق.

## الكمبيوتر
حزمة Windows المرفقة تعمل بعد فك الضغط وفتح `ArshAdmin.exe`. لا يلزم فتح الموقع لتشغيل صفحاتها، ولكن الاتصال بالإنترنت مطلوب للبيانات.
لإعادة إنتاجها استخدم `bun run native:windows`. الحزمة المرفقة لـWindows 64-bit فقط؛ ليست مثبتًا وليست موقعة رقميًا.

## أندرويد
ثبّت Android Studio وJDK 21 أو أحدث ثم:

```sh
bun run native:build
cd native
node ../node_modules/@capacitor/cli/bin/capacitor sync android
node ../node_modules/@capacitor/cli/bin/capacitor open android
```

من Android Studio اختر Build APK(s). ملف APK المرفق نسخة تطوير قابلة للتثبيت على أندرويد وليس آيفون أو إصدار متجر، ويلزم مفتاح توقيع خاص بك لإصدار دائم. احتفظ بمفتاح التوقيع منفصلًا عن الأرشيف. قد تحتاج إزالة النسخة التجريبية قبل تثبيت إصدار بتوقيع مختلف.
النسخة تستخدم البريد وكلمة المرور فقط؛ استعادة كلمة المرور تتم من الموقع.

## تحديث تطبيق الهاتف
ثبّت نسخة 1.1 مرة واحدة فوق النسخة القديمة إن كان التوقيع متطابقًا. لا يحوّلك التطبيق إلى الموقع عند فتحه، ولا ينزل تحديثات تلقائيًا. اضغط زر الإعدادات العائم ثم «تحديث التطبيق» لتنزيل أحدث نسخة منشورة وحفظها محليًا. عند فشل التنزيل يحتفظ بالإصدار الحالي، وعند فشل تشغيل النسخة الجديدة يرجع إلى نسخة صالحة. تغييرات الإضافات الأصلية تتطلب APK جديدًا.

لتجهيز تحديث الصفحات بعد تعديلها:
```sh
bun run native:build
node native/package-update.mjs
```
انشر الموقع بعد ذلك مع ملفات `public/app-updates`. مجرد نشر الموقع دون تجهيز حزمة التحديث لا يحدّث التطبيق المثبّت. لا يشمل تحديث الصفحات تعديل ملف n8n.

## تغيير العنوان لاحقًا
زر إعدادات التطبيق المحلي يسمح بتغيير عنوان خدمة الإدارة إلى أي استضافة HTTPS متوافقة، ومعه خيار نقل خدمة البيانات. لا يمكن حذف خادم استقبال البوت؛ n8n يحتاج عنوانًا عامًا للوصول إليه. بعد نقل الخادم عدّل عناوين عقد Panel في n8n وإعدادات الاتصال العام، وأعد ضبط السر المشترك في الطرفين بأمان. لا تغيّر إعدادات واتساب العاملة.
